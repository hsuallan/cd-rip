# CD Digitization & Automated Tag Archiving System (CD-RIP Tool)

An efficient, automated digitization solution for doujin and music CDs. Powered by the native Windows SCSI MMC protocol for bit-perfect lossless audio extraction, supporting maximum FLAC compression (Level 8), AI-assisted CSV metadata tagging, clipboard cover art embedding, and a modern multi-language Material 3 desktop GUI.

---

## 🌟 Key Features

1. **Modern Material 3 Desktop GUI**: Built with Flet, supporting dynamic runtime language switching (Traditional Chinese, English, Japanese, Simplified Chinese) and light/dark theme modes.
2. **Native Bit-Perfect CD Ripping**: Performs digital audio extraction (DAE) directly via native Windows SCSI MMC commands, **with no external ripping or transcoding software required**.
3. **High-Fidelity FLAC Compression**: Exports to 16-bit 44.1kHz stereo lossless FLAC (defaulting to maximum Level 8 compression).
4. **Efficient Dual-Tab Modular Workflow**:
   - **Continuous Rip Tab**: Real-time TOC detection, dual progress indicators, fast batch ripping, and automatic tray ejection upon completion.
   - **Batch Archiving Tab**: AI CSV metadata parsing with instant track preview, clipboard / file cover embedding, single album and sequential batch archiving.
5. **Seamless Tagging & Artwork Management**: Paste AI-generated CSV metadata and clipboard images (`Ctrl+V`) directly in the UI, automatically normalized into standard `cover.jpg`.
6. **Zero Configuration Defaults**: Automatically detects and initializes local default paths based on the application location on first launch.

## 🚀 Quick Start & Download

### Method 1: Download Prebuilt Executable (Recommended, No Python Required)
For standard users, there is no need to set up a Python environment. Simply download the latest release package (e.g., `CD-Rip-Tool-windows-x64.zip`) directly from [GitHub Releases](../../releases). Extract the ZIP archive and launch `CD-Rip-Tool.exe` to get started immediately.

For development or customization, ensure Python 3.10+ and dependencies are installed, then run:


## 🤖 AI Metadata Prompt

When working in the "Batch Archiving" tab, this tool allows you to paste CSV-formatted track data generated by AI models (such as Gemini, ChatGPT, or Claude) directly into the text field to automatically parse, tag, and rename audio files.

### 📖 How to Generate Album CSV and Cover Art

1. Copy the **AI Prompt** below.
2. Open your preferred AI model (models with web-browsing capabilities like Gemini or ChatGPT Plus are recommended).
3. Send the prompt along with the **Album Title, Circle Name, Release Event (e.g., M3, Comiket), or product URL**.
4. The AI will retrieve the tracklist, vocalists, composers, and lyricists, outputting a standard CSV code block followed by a high-resolution cover image URL.
5. In CD-RIP Tool's "Batch Archiving" tab:
   - Copy the CSV text from the code block and paste it into the "CSV Metadata Text" field; the track table preview updates immediately.
   - Copy the album cover image (or copy image directly from the browser) and click "Paste from Clipboard" or press `Ctrl+V`.

---

### 📋 AI Prompt Template

```text
You are a music assistant bot.
Search for album info in detail and organize it into CSV format.
The CSV string must be enclosed inside a ```csv ``` code block.
The CSV format must strictly follow the header below:

%track%,%title%,%genre%,%artist%,%year%,%album%,%albumartist%,%composer%,%lyricist%

Field rules:
1. Make sure all properties are included in the header. If a field value is unknown or not specified, leave it blank.
2. %track%: Track number padded with leading zero (e.g., 01, 02).
3. %title%: Track title.
4. %genre%: Music style or genre (e.g., J-Pop, Instrumental, Electronic, Rock).
5. %artist%: Track vocalist. If featuring multiple vocalists, use " & " to connect all vocalists.
6. %year%: Album release year (4 digits, e.g., 2026).
7. %album%: The name of the album.
8. %albumartist%: Circle name, band name, or main producer.
9. %composer%: The person who wrote the music or mastering/sound engineer. If not specified, leave empty.
10. %lyricist%: The person who wrote the lyrics. If not specified, leave empty.
11. Instrumental version tracks do NOT need %artist% and %lyricist% (leave both blank).

After the CSV code block, please also provide the direct link to the album cover image (preferably high resolution).

Album to search: [Insert Album Name / Circle / Catalog Number / Event here]
```
